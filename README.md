# homebrew-ghost

> [!IMPORTANT]
> This tap has moved to [ghost-language/homebrew-tap](https://github.com/ghost-language/homebrew-tap),
> which carries Ghost, Lumen, and anything else the project ships.
>
> ```sh
> brew untap ghost-language/ghost
> brew tap ghost-language/tap
> brew install --cask ghost-language/tap/ghost
> ```

The `ghost` cask here is frozen at `1.0.0-beta.3` and will not be updated
again. It still installs, so nothing breaks if you do not move — but you will
not see new releases until you re-tap.
